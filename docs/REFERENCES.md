# Reference study and differentiation

Lumera was informed by public anemia ML and conjunctiva-screening repositories, while keeping its implementation independent.

Key directions studied: machine-learning evaluation, conjunctiva segmentation/classification, smartphone screening, image preprocessing, colour handling, and field-health workflows.

Lumera intentionally differs by using a compact clinical-tool interface, an explicit no-model-no-estimate rule, calibration as a measurable experiment, patient-level leakage prevention, and uncertainty/image rejection as core behavior.
